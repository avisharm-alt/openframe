# Naming

**The working name "OpenFrame" should not be kept for a public launch.** I have not renamed anything; this page is for you to decide.

## What I found

Quick web checks (not a legal search) turned up existing uses of the name:

- **OPENFRAME**: a registered trademark of TmaxSoft, used for mainframe modernisation software.
- **OpenFrame** by Flamingo AI: an AI product.
- **openframe.io**: already registered.

An unrelated charity-adjacent project with the same name as enterprise software is easy to confuse in search results, and a registered trademark in software can lead to a takedown request. A real clearance search (Canadian Trademarks Database, CIPO, plus a domain and social-handle check) is the owner's to do before choosing.

## Proposed names

None of these has been searched. Check each before you get attached.

| Name | Why | Risk to check |
|---|---|---|
| **Warm Hands Network** | Plain, kind, says what it does; works for winter and all year | "Warm Hands" is a common phrase; check local charities |
| **Doorstep Care** | Matches the pickup-at-the-door and delivery-to-the-agency idea | Many "doorstep" delivery businesses |
| **Bundle Up** | Short and friendly; fits winter gear and kits | Generic; check apparel brands |
| **Neighbourhood Kits** | Describes neighbours and kits | Long; "kits" undersells the specific-request model |
| **Kit Collective** | Student-collective feel | Same "kits" caveat |

If the project leads with specific requests rather than kits, **Warm Hands Network** or **Doorstep Care** fit best.

## Changing the name later

The name appears in `package.json`, the page title and header (`src/app/layout.tsx`), the About, Privacy, Account and Admin pages, `src/lib/copy.ts`, `src/lib/auth.ts`, `src/lib/email.ts`, the email subjects in `src/lib/services/notifications.ts`, and the docs. A case-sensitive search for `OpenFrame` finds them all. Environment variables, tables and the demo accounts do not use it.
